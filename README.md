# JETS (Just Enough Tavern Search)

酒馆全局搜索插件：角色 / 世界书 / 聊天历史 / 预设 / 设置 / 按钮一键直达。

## 能解决什么问题
- 设置太多找不到？直接搜按钮名或功能名。
- 角色、世界书、聊天记录太多？一处搜索全局定位。
- 移动端操作麻烦？提供顶部搜索入口。

## 主要功能
- Search Everywhere：角色 / 世界书 / 聊天历史 / 预设 / 设置 / 功能按钮
- 聊天历史全量索引，后台分批加载，消息新增实时更新
- 支持中文本地化文本检索
- 回车直接执行（自动展开折叠项）
- Alt+K 快捷键 + 顶部放大镜入口按钮（PC/移动端）

## 安装
1. 打开 SillyTavern → 顶部【扩展】图标
2. 点击【安装扩展】
3. 粘贴仓库地址（二选一）  
   - GitHub：`https://github.com/Moeblack/st-jets`

推荐：安装 ST API Wrapper，可提升聊天跳转/滚动稳定性与索引体验。

## 使用
- 打开：`Alt + K` 或顶部放大镜按钮（PC/移动端）
- 输入关键词，按回车执行
- 上下键选择结果，ESC 关闭
