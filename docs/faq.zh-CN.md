# JETS 常见问题（FAQ）

## 1. 我搜索不到按钮/设置
- 可能该面板还没打开过  
  - 先打开一次对应面板（世界书/设置/扩展），再搜索  
- 按钮没有文字/提示时会被跳过（避免误导）

## 2. 搜索结果点击没反应
多数情况是按钮在折叠区域中未展开。  
JETS 会自动展开抽屉并点击；若失败，请再执行一次。

## 3. 聊天记录太多会卡吗？
JETS 默认会全量索引聊天消息，并在新增时实时更新。  
为了性能，聊天会在后台分批加载，结果会逐步补齐。

## 4. 快捷键 Alt+K 不生效
可能被浏览器或系统快捷键占用。  
可使用移动端入口按钮，或在浏览器设置里取消冲突快捷键。

## 5. 移动端没有放大镜按钮
请确认：  
- 已安装并启用扩展  
- 视口宽度足够小（手机模式）  
若仍无显示，尝试刷新或清空缓存后重进。

## 6. 会上传我的数据吗？
不会。JETS 仅在本地读取酒馆已有数据，不会上传聊天内容、设置或角色信息。
