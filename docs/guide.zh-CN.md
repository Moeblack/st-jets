# JETS 使用教程（小白向）

这是一份尽量简单的使用说明，适合第一次用酒馆插件的同学。

## 1. 这是什么
JETS（Just Enough Tavern Search）是一个“酒馆全局搜索”插件。  
它能帮你在**角色、世界书、聊天历史、预设、设置、功能按钮**里快速定位，并一键执行。

## 2. 怎么安装
1. 打开 SillyTavern → 顶部【扩展】图标  
2. 点击【安装扩展】  
3. 粘贴仓库地址  
   - GitHub：`https://github.com/Moeblack/st-jets`

推荐：安装 ST API Wrapper，可提升聊天跳转/滚动稳定性与索引体验。

安装完成后，刷新页面或重新打开酒馆即可使用。

## 3. 怎么用（最简单的 3 步）
1. 按 `Alt + K` 打开搜索框  
2. 输入关键词（比如“世界书 / 预设 / 关闭聊天 / 背景”）  
3. 回车执行，或上下键选择后回车

### 移动端
移动端会在顶部出现一个放大镜按钮，点它即可打开搜索。

## 4. 能搜什么
- **角色**：角色名、关键词  
- **世界书**：条目标题、关键词  
- **聊天历史**：聊天名、内容片段（全量索引）  
- **预设**：预设名、模型设置  
- **设置**：设置项文本、中文本地化  
- **按钮**：大多数功能按钮（menu_button / drawer-icon 等）

聊天新增消息会实时进入索引，无需刷新页面。  
首次使用会在后台分批索引全库聊天，数量多时需要一点时间补齐。

## 5. 常见小技巧
- 搜不到内容：多半是拼写或没打开过对应面板  
  - 先打开一次“世界书/设置面板”，再搜索  
- 按钮执行失败：再搜索一次并回车即可  
- 快捷键冲突：优先用移动端按钮或在浏览器中取消冲突快捷键

## 6. 快捷键
- 打开/关闭：`Alt + K`
- 上下选择：`↑ / ↓`
- 执行：`Enter`
- 关闭：`ESC`

## 7. 隐私与安全
JETS 不会上传任何聊天内容或设置，也不会请求第三方域名。  
如未来新增第三方请求，会在文档和 README 中显著说明。
