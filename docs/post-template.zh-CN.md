# 发帖模板（酒馆插件区）

标题：
【JETS（Just Enough Tavern Search）】酒馆全局搜索：角色/世界书/聊天历史/预设/设置/按钮一键直达

正文：
**📝 插件简介**  
JETS 是一个酒馆全局搜索插件，帮你在角色、世界书、聊天历史、预设、设置与功能按钮里快速定位，一键直达。

**✅ 能解决什么问题**  
- 设置太多找不到？直接搜按钮名/功能名  
- 角色、世界书、聊天记录太多？全局搜索秒定位  
- 想要一步执行功能？回车直接点击  

**✨ 功能亮点**  
- 全局搜索：角色 / 世界书 / 聊天历史 / 预设 / 设置 / 功能按钮  
- 聊天历史全量索引，后台分批加载，消息新增实时更新  
- 支持中文本地化搜索  
- 回车直接执行（自动展开折叠项）  
- 移动端入口按钮  

**🚀 安装方法**  
1. 打开 SillyTavern → 顶部【扩展】图标  
2. 点击【安装扩展】  
3. 粘贴仓库地址  
   - GitHub：`https://github.com/Moeblack/st-jets`

推荐：安装 ST API Wrapper，可提升聊天跳转/滚动稳定性与索引体验。

**📘 使用说明**  
- 快捷键：`Alt + K`  
- 移动端：顶部放大镜按钮  
- 输入关键词 → 回车执行  

**🔒 安全与隐私声明**  
- 本插件不收集任何个人数据  
- 不上传聊天内容或设置  
- 第三方请求域名：无
